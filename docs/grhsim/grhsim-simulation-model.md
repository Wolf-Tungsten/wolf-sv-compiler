# GRHSIM 仿真模型

> 状态：新架构首份文档。本文定义 GRHSIM 的仿真模型 ⟨S, S_edge, G⟩ 和 eval 的
> 不动点执行语义。本文不定义具体 op 列表；操作语义、host 调用条目和边缘事件
> 细节由后续文档定义。旧 GRHSIM-AM 系列文档（[deprecated/](deprecated/) 目
> 录）已废弃，仅作历史参考。

## 1. 模型定义

GRHSIM 把一个仿真对象形式化为三元组：

```text
Sim = ⟨S, S_edge, G⟩
```

- `S`：电路状态。包含输入输出和状态单元值，见第 2 节。
- `S_edge`：事件边缘跟踪存储。保存被跟踪信号上一轮求值时的值，供边缘检测
  与当前值比较，见第 3 节。`S_edge` 与 `S` 并列、独立于 `S`：它参与 `G`
  的求值，但不参与 `S' == S` 的不动点比较。
- `G`：仿真流图。`G = ⟨V, E, H⟩`，`V` 是操作顶点，`E` 是顶点间的数据流
  边，`H` 是 host 环境调用表，见第 4 节。

仿真行为归结为一条规则：每次调用仿真 eval 函数，对 `S` 反复应用 `G`，
直到状态不再变化（达到不动点）后返回：

```text
do { (S', S_edge') = G(S, S_edge) } while (S' != S)
```

第 5 节给出 eval 的完整定义。

## 2. 电路状态 S

`S` 是三个分量的元组，每个分量是从标识到逻辑值的有限映射：

```text
S = (S_in, S_out, S_state)
```

- `S_in`：输入端口值。以输入端口标识为键。eval 期间由调用方固定，`G` 不
  写入 `S_in`。
- `S_out`：输出端口值。以输出端口标识为键，是 `G` 求值结果的一部分。
- `S_state`：状态单元值。以状态单元标识为键，保存触发器、锁存器和存储器
  等状态单元的当前值。寄存器与存储器在语义上等价，不作区分：二者只是值的
  数据类型不同——寄存器的值是逻辑向量，存储器的值是按地址索引的数组。

逻辑值的编码（位宽、多态表示）不在本文定义，由后续操作语义文档规定。

## 3. 事件边缘跟踪存储 S_edge

`S_edge` 以被跟踪信号的标识为键，保存这些信号上一轮求值时的值，供边缘
检测（上升沿、下降沿、任意变化）与当前值比较。其更新规则见 5.3 节。

`S_edge` 不属于 `S`：它参与 `G` 的求值（被边缘检测读取、每轮被同步），
但不参与 `S' == S` 的不动点比较。原因是 `S_edge` 按轮同步、总比被跟踪
信号滞后一轮（5.3 节）：若把它计入比较，即使电路状态已经稳定，`S_edge`
仍会在该轮发生变化，从而强制多出一轮无意义的迭代。

## 4. 仿真流图 G

```text
G = ⟨V, E, H⟩
```

### 4.1 顶点 V

`V` 是顶点集。每个顶点表示一个操作 op：求值时从 `S`、`S_edge` 和（经 `E`
传来的）上游 op 结果读取输入，计算后写出结果，结果经 `E` 流向 downstream
op 或写回 `S` 的某个分量。

本文不定义 op 的种类列表（opcode、操作数、写出目标），由后续操作语义文档
定义。本文只对 op 作如下约束：

- op 是确定的：相同输入产生相同输出。
- op 只能通过 `H` 访问宿主能力（见 4.3 节），不得有其他隐式外部通道。

### 4.2 边 E

`E ⊆ V × V` 是有向边集。边 `(u, v) ∈ E` 表示 `u` 的输出是 `v` 的输入，
即 op 之间的数据流向。

`E` 决定 op 间的数据依赖，是一轮求值内 op 执行顺序的依据（见 5.2 节）。
`E` 允许成环：环对应组合反馈、锁存器环路等结构。环上一轮内无法按依赖
顺序求值的部分，由 eval 的不动点迭代处理（见第 5 节）。

### 4.3 host 环境调用表 H

`H` 是 host 环境调用表。所有宿主动作——DPI 调用、`$time`、`$display` 等
系统函数与系统任务——都注册为 `H` 中的条目。条目记录宿主例程的标识、参数
签名和绑定。

需要宿主能力的 op 持有 `H` 的条目索引，求值时经 `H` 发起调用。`H` 是 op
访问宿主环境的唯一通道：

- 查询类调用（如 `$time`）返回宿主当前状态，本身不改变 `S`。
- 副作用类调用（如 `$display`）向宿主产生可观察效果。副作用的触发时机
  与跨迭代去重规则（同一 op 在一次 eval 的多轮迭代中可能被重复求值）由
  后续文档定义。

`H` 属于 `G` 而不属于 `S`：host 条目在 `G` 构建时注册，eval 的不动点比较
不涉及 `H`。

## 5. 仿真行为：eval

### 5.1 不动点语义

每次调用仿真 eval 函数，求解 `S` 在 `G` 下的不动点，达到不动点后返回：

```text
eval(S):
    loop:
        (S', S_edge') := G(S, S_edge)   -- 对整张流图求值一次（5.2 节）
        if S' == S:                     -- S 达到不动点，返回稳定状态
            S_edge := S_edge'
            return S'
        (S, S_edge) := (S', S_edge')    -- 未稳定，以新状态继续迭代
```

即 `do { (S', S_edge') = G(S, S_edge) } while (S' != S)`：每次 eval 至少对
`G` 求值一次；若求值后 `S` 未变，立即返回。不动点判定只看 `S`，`S_edge`
的逐轮同步不影响收敛判定。

`eval` 返回时，`S` 是稳定状态：寄存器与存储器的新值生效，输出可被调用方
采样；`S_edge` 已与稳定态信号值同步，作为下一次 eval 边缘检测的基准。

### 5.2 G(S, S_edge)：一轮求值

`G(S, S_edge)` 表示给定状态 `S` 和边缘跟踪存储 `S_edge`，对整张流图求值
一次，产生新状态 `S'` 和同步后的 `S_edge'`：

- `V` 中每个 op 在一轮内恰好求值一次。op 的输入取自本轮起始状态 `S`、
  `S_edge`，以及本轮已求值的上游 op 经 `E` 传来的结果。
- 一轮内 op 的执行顺序与 `E` 的数据依赖一致：`(u, v) ∈ E` 时 `u` 先于
  `v` 求值。`E` 成环时，环上顶点按实现固定的一种打破环的顺序求值，未
  传播到位的值留待下一轮迭代收敛。
- op 写出的结果汇集成本轮末态 `S'`：`S_out`、`S_state` 中被写入的键取新值
  （存储器的单地址写入表现为该状态单元数组值中对应元素的更新），未被写入
  的键保持原值；`S_in` 不变；`S_edge` 按 5.3 节更新。

对同一 `G`，实现必须固定一轮内的求值顺序；在此且 `H` 各次调用返回相同的
前提下，`G` 是 `(S, S_edge)` 的确定函数（`H` 允许有状态，见 5.5 节）。

### 5.3 边缘跟踪存储的更新

`G` 的每次应用同时更新 `S_edge`：本轮求值结束时，`S_edge` 中各被跟踪信号
的值同步为本轮起始时该信号的值。

因此同一信号边缘只在它发生的那一轮可见：边缘检测在本轮比较当前值与
`S_edge` 中的旧值而触发；下一轮 `S_edge` 已更新，该边缘不再重复触发。
`S` 达到不动点时各信号值在本轮已不再变化，`S_edge` 同步后即与各信号
当前值一致，eval 返回后它即成为下一次 eval 检测边缘的旧值基准。

### 5.4 状态相等与不动点

`S' == S` 当且仅当三个分量逐点相等（同键同值）。由于 `S_in` 在 eval 期间
固定，实际决定不动点的是 `S_out`、`S_state` 两个分量。`S_edge`
不参与比较，原因见第 3 节。

### 5.5 确定性与终止性

- 确定性：`H` 允许是有状态的（如 `$time`、DPI 绑定的宿主内部状态），其返
  回可随宿主状态变化，因此同一 `⟨S, S_edge, G⟩`、同一初始状态的两次 eval
  结果可以不同，模型不保证可复现性。模型只保证条件确定性：实现固定一轮内
  的求值顺序（5.2 节）后，若 `H` 各次调用的返回相同，则 eval 的迭代过程与
  结果唯一。
- 终止性：模型不保证任意 `G` 都收敛——含零延迟振荡环的电路会使状态在
  迭代中持续翻转，`eval` 不终止。合法设计应在有限轮内收敛；实现可设置
  迭代轮数上限，超过上限时以振荡诊断终止本次 eval，而不是无限循环。

## 6. 本文不定义的内容

以下内容由后续文档定义：

- op 集合与逐 op 语义（opcode、操作数、写出目标、边缘检测操作的具体行为）。
- 逻辑值的编码与位宽规则。
- `H` 的具体条目、参数签名与绑定 ABI。
- 副作用类 host 调用的触发时机与跨迭代去重规则。
- eval 的调用时机：时间推进、时钟与输入激励如何由调用方驱动进 `S_in`。
- `G` 的构建流程：从 GRH 到 `⟨V, E, H⟩` 的 lowering。
